Стан після rollback
ДО запиту: SELECT COUNT(*) FROM records;
Результат: 10
ПІСЛЯ запиту: SELECT COUNT(*) FROM records;
Результат: 10
ПІСЛЯ: SELECT COUNT(*) FROM records WHERE code = ?;
Параметр: V13-ROLLBACK11
Результат: 0
PASS: кількість не змінилася; перший елемент відсутній.
Підраховано SQL COUNT(*), незалежно від limit та offset API.
